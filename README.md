# FOUNDEXA

Founder Networking & Startup Community — an initiative by TEJSTARTER.

> Where Founders Connect, Ideas Grow.

## Project

A responsive, premium static website for FOUNDEXA. The current version is intentionally backend-ready: the Join form validates on the client and can be connected later to a database or form/API service.

## Deploy

The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`. Enable **Settings → Pages → Source → GitHub Actions** to publish it. GitHub Pages supports custom Actions workflows for static sites.
